L2 · Central Layer · System Kernel
Nervus OSnervud · Go kernel · ~16k lines
The core of the whole board. All App instructions must go through here: bus, permissions, arbitration, package management, and capability routing are all inside the kernel. It only schedules and arbitrates, does not touch high-frequency physical control— that's DimOS's job.
