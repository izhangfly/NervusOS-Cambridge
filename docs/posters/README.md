# NervusOS posters (ADVX 2026)

The three 600 × 900 mm boards the team showed at the AdventureX 2026 hackathon in Hangzhou: the technical
architecture, the ecosystem and business model, and the prospects with the five sponsor tracks. Each board is one
self-contained HTML file rendered to a print PDF with headless Chrome; `HANDOFF.md` explains the conventions and how
to edit and re-export them.

| Board | Source | Print PDF | Preview |
|---|---|---|---|
| ① Technical architecture | `board-a-layers.html` | `NervusOS-Board1-Technical.pdf` | `NervusOS-Board1-Technical.png` |
| ② Ecosystem and business model | `board-c-central.html` | `NervusOS-Board2-Ecosystem.pdf` | `NervusOS-Board2-Ecosystem.png` |
| ③ Prospects and the five tracks | `board-3-tracks.html` | `NervusOS-Board3-Prospects.pdf` | `NervusOS-Board3-Prospects.png` |

The boards were made in Chinese and translated to English here; the English text runs longer, so board ① uses
slightly smaller body text and board ② a smaller headline than the originals. `board-b-flowchart.html` is the
dropped flowchart board and `poster.html` / `single-board-backup.html` the earlier single-board version, kept for
reference.
