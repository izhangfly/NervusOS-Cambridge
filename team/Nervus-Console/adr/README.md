# Architecture Decision Records (ADR)
**Architecture Decision Records**

**Please add the following at the top of each file**
- Status: Accepted Denied Creating Review
- Date: 20xx-xx-xx
- Decision Owners: Nervus-OS Core Team (or Somebody else)
- Writers: Your name

This folder should store ADR related files

This should only record when there is a controversy and a decision is made after discussion or for important decisions or certain special situations

Naming rules:
The naming format is: <number>-<title>.md
For example:
0001-example.md

Template:
0001-example.md
