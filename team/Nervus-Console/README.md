# Nervus-Console

Unified Management Repository of Nervus OS

Purpose of Each Folder
adr: Architecture Decision Records
This should only be recorded when there is a dispute and a decision is made after discussion, or for important decisions or certain special situations

meeting: Meeting Minutes

plan: Plan related

nervud: Nervus kernel related

nervus-system-server: System service related

nervus-system-software: System software related

**Please check the readme.md in the folder carefully before adding anything**
